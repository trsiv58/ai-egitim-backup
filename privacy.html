Privacy Policy

Application: AI-EGITIM-BACKUP

Last updated: November 9, 2026

1. Purpose

AI-EGITIM-BACKUP is a personal backup application intended to store and recover encrypted backups of the AI-EGITIM educational project.

2. Google User Data Access

The application requests Google Drive access to create, upload, list, download, and manage backup files in the account owner's Google Drive. Access is limited by the permissions granted during Google OAuth authorization.

3. Data Use

Google Drive access is used exclusively for backup storage, integrity checks, and recovery. Google user data is not sold, used for advertising, or shared with third parties for marketing.

4. Data Storage and Security

The planned backup workflow encrypts project data locally using Restic before transferring encrypted backup files through Rclone to Google Drive.

OAuth credentials are intended to remain on the account owner's local computer. Encryption passwords and OAuth tokens must not be published in source repositories.

5. Data Sharing

Backup files are stored in the account owner's Google Drive. Google processes stored data according to its applicable terms and policies. The application does not intentionally transmit backup contents to unrelated services.

6. Data Retention and Deletion

Backup data is retained until the account owner deletes it or applies a backup retention policy. The account owner can delete backup files from Google Drive and revoke application access through Google Account security settings.

7. Contact

For privacy-related questions, contact the application developer using the support email shown on the Google OAuth consent screen.
