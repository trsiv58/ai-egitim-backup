AI-EGITIM-BACKUP

AI-EGITIM-BACKUP is a personal backup application designed to support the secure storage and recovery of files belonging to the AI-EGITIM educational project.

Purpose

The application uses Rclone to connect to the account owner's Google Drive and transfer locally encrypted backup data.

How It Works

Backup data is encrypted locally using Restic before being transferred to Google Drive. The application is intended for personal use by the account owner.

Google Drive Access

Google Drive authorization is used to store, access, and manage backup files. The application does not sell Google user data or use it for advertising.

Privacy

For information about data access, storage, and protection, please read our Privacy Policy.
